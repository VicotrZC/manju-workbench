# 风格 → 光线/画质/镜头倾向映射表

主流风格参考，导演按表选用并可补充；表内为各风格的典型约定，具体以用户确认为准。

> **光影命名唯一来源**：本表「光影命名」列每个命名都必须能在 [lighting-library.md](lighting-library.md) 中找到；组合命名（如「分割光+顶光戏剧」）逐项都须是库内条目。库外词（自然光/留白漫射/钨丝暖调/三点布光/强对比等）属光质、影调或布光方式，一律写进「光线基调」列，不写进命名。影调范围/对比度属风格段第六维，不在本列。

> **画质词库对冲配比（第 5 步硬规则，选材/输出必查）**：上表「画质词库」列多为加光方向词（高光/辉光/颗粒/对比），选用时**必须成对补入哑光对冲词**——「高光受控不过曝」「中高对比且暗部保留层次」「哑光质感」「真实皮肤微纹理（毛孔/绒毛/次表面散射自然）」；halation/辉光类默认降级「极轻微」；人物场景画质段必含皮肤微纹理词，无人物主体段按材质微纹理（表面粗糙度/磨损/半哑光）配比；反向限制必含「塑料皮肤/蜡像质感/油光满面/高光溢出/磨皮感」。
