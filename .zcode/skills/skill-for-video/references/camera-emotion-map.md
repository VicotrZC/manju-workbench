# 机位/运镜 → 触发条件 → 情绪效果 映射表（决策查表）

镜头语言不是「填表」，是「先按情绪选对技法，再落到颗粒度」。本表用于**决策**：每镜开工前，先判断本镜主角/观众处于什么情绪、什么剧情状态，从表里选定机位/运镜，再用第 7 步「视角语义」写清用意。

> **与正文分工**：本表管「选哪个」（决策）；第 6/7 步管「写多细」（颗粒度）。仰拍/俯拍/主观 POV/正反打等正文已列名的技法，本表补其「触发条件 + 情绪效果 + 量化参数」；荷兰角（roll）是机位第四维（横滚），须单独声明。**「量化参数」列中的数字（°/秒、秒级、度数）仅作创作备注、不进提示词；定性写法（如「运动方式『推』」「方位角正侧面」）才进提示词。**

| 技法 | 触发条件（何时用） | 情绪效果（为什么用） | 量化参数 / 写法 |
|---|---|---|---|
| 侧拍（Profile） | 人物沉默 / 观察 / 倾听 / 疏离时 | 疏离、审视、隔阂、旁观 | 方位角：正侧面 90°；多用于关系冷却或内心独白 |
| 跟拍（Follow） | 人物行走 / 奔跑 / 进出空间时 | 代入感、陪伴感 | 运动方式「跟」；节奏随主体速度，丝滑无抖动 |
| 荷兰角（Dutch Angle） | 情绪失衡 / 内心混乱 / 失控时 | 不安、错乱、失控 | 横滚角 15°–25°；俯仰/方位/高度仍须并列给出 |
| 肩后镜头（OTS） | 对话 / 对峙 / 紧张交流时 | 代入对话、强化冲突 | 方位角落在对话者肩后；与正反打衔接 |
| 正反打（Shot/Reverse Shot） | 对话段落，尤其冲突对话 | 对话节奏、捕捉微表情 | 视角连续性：正反打；同轴守 180° 轴线 |
| 仰拍（Low Angle） | 权力者出场 / 情绪爆发 / 重燃希望时 | 权威、压迫、能量、重生 | 仰视 + 机位高度约膝盖高度向上 |
| 俯拍（High Angle） | 人物脆弱 / 孤独 / 无助时 | 渺小、无力、被审视 | 俯视 + 机位高度约 2–3m 向下 |
| 环绕（Orbit） | 内心翻涌 / 激烈情绪变化时 | 沉浸、情绪包裹 | 运动方式「环绕」约 15°/秒 |
| 手持微颤（Handheld） | 紧张 / 不安 / 冲突 / 临场感需求时 | 临场感、紧张、真实感 | 运动方式「手持」+ 轻微晃动 |
| 主观 POV | 共情时刻 / 让观众代入角色时 | 代入角色内心、共情 | 视点：主观 POV + 视线方向/视点高度/呼吸感/跟随速度 |
| 急推（Quick Push-in） | 情绪爆发 / 突然转折 / 真相揭示时 | 冲击、压迫、惊醒 | 运动方式「推」约 0.3 秒快速推近 |
| 缓慢推近（Slow Push-in） | 情绪累积 / 沉默时刻 / 重量感需要时 | 逼近、重量感、情感深化 | 运动方式「推」3–5 秒、S 形缓动曲线 |

## 使用规则

1. **先决策、后描述**：每镜先按本镜情绪/剧情状态查表选定技法，再落到第 6/7 步颗粒度。
2. **一镜一主技法**：可叠加（如 OTS + 缓慢推近），但情绪语义只由主技法决定，避免情绪打架。
3. **定性进提示词、量化进备注（同 SKILL.md 第 7 步硬规则）**：选定技法后，只把「量化参数」列的**定性写法**写进运镜/机位描述——运动方式（推/跟/环绕/手持）、方位角（正侧面/正面）、视点类型等；**量化数字（°/秒、秒级、度数、机位高度米数）仅作创作备注、不进提示词**。禁止「大概 / 适中」——定性档必须明确。
4. **荷兰角是第四维**：声明荷兰角时，俯仰角/方位角/机位高度仍须并列给出，禁止只写「斜一点」。
5. **情绪词库反哺视角语义**：第 7 步「视角语义」从 [emotion-library.md](emotion-library.md) 按情绪基调+强度选词，本表「情绪效果」列为其技法侧简版，避免每镜都写「压迫感」。
