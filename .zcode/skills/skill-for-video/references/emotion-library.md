# 情绪词库（视角语义选词 + 情绪→技法反向入口）

情绪是分镜的发动机：先定情绪，再选技法，最后写清用意。本库是 [camera-emotion-map.md](camera-emotion-map.md)「情绪效果」列的**完整版与反向入口**——camera-emotion-map 按「技法 → 情绪」正向查，本库按「情绪 → 技法」反向查，二者是同一映射的两个方向。

> **与正文分工**：本库管「用什么词」（情绪基调 + 强度分级）；第 7 步「视角语义」从本库选词，第 7 步「选择逻辑」先按情绪定基调再选技法。强度分级（轻/中/重）对应技法强度——轻度失衡用手持微颤，重度失衡才用荷兰角，不得一上来就上重技法。

|---|---|---|---|

## 运镜速度分档（速度 = 情绪强度的物理载体）

速度不是装饰，是情绪强度的物理表达——同一运镜，速度不同，情绪相反（急推=冲击惊醒 vs 缓推=累积重量）。按本镜情绪强度选速度档（定性：静止/缓/中/快/急促）写进提示词；表中「量化范围」的秒级/角速度仅作创作备注、不进提示词。再落到 [camera-emotion-map.md](camera-emotion-map.md) 取对应技法。

| 速度档 | 量化范围 | 情绪基调（词汇） | 典型运镜 |
|---|---|---|---|
| 静止 | 0（固定机位） | 安定 · 疏离 · 审视 · 平静 · 亲密 · 释然 | 固定机位 |
| 缓速 | 3–5 秒级，S 形缓动 | 累积 · 重量感 · 悲伤 · 情感深化 · 沉静 | 缓推 / 缓拉 / 缓摇 / 缓升 |
| 中速 | 1–2 秒级，匀速 | 叙事 · 跟随 · 陪伴 · 观察 · 代入 | 跟 / 移 / 平移 / 匀速摇 / 环绕 15°/秒 |
| 快速 | 0.3–0.5 秒级 | 冲击 · 惊醒 · 愤怒 · 爆发 · 紧张 · 权威 | 急推 / 急拉 / 快摇 / 快升 |
| 急促 | <0.3 秒，连击 / 高频 | 恐慌 · 失控 · 眩晕 · 崩坏 · 窒息 | 急促推拉 / 手持高频微颤 / 快环绕 30°/秒 |

**速度 ↔ 强度对照（选速度先看情绪强度）**：轻度情绪 → 静止/缓速；中度情绪 → 缓速/中速；重度情绪 → 快速/急促。禁止为「动」而动——情绪越静速度越慢，情绪越失控速度越快越急。

## 使用规则

1. **先定基调、再选强度**：每镜先定情绪基调（行），再定强度（轻/中/重）——强度决定技法轻重（轻度失衡→手持微颤，重度失衡→荷兰角）。
2. **选词进视角语义**：第 7 步「视角语义」从「强度分层」列选词（如「疏离」「失控」「惊醒」），不自己造模糊词，也不每镜都写「压迫感」。
3. **反向查技法**：定基调后先按本库「运镜速度分档」定速度档，再按「典型技法倾向」列去 [camera-emotion-map.md](camera-emotion-map.md) 取角度/时长量化。
4. **无专属运镜的情绪用「静」**：温暖/悲伤/爱意/释然等情绪不靠运镜推动，用固定机位（悲伤/释然可缓慢拉远留白）+ 景别/景深/视点 + 光线落点表达，禁止为「动」而动、乱加速技法（急推/环绕/荷兰角等）。
5. **一镜一基调**：一镜只落一个情绪基调，情绪转折必须换镜或明确过渡，禁止一镜内情绪打架。
