# 后端能力矩阵（一致性三件套 × 后端）

「文字逐字一致 ≠ 像素级一致」——三件套是把文字意图落到像素级一致的手段；但每个后端对三件套的支持不同。执行生成前先查本表，确定该后端「支持 / 部分支持 / 不支持 → 降级动作」，并把实际降级写入分镜文档「全局」行。

| 后端 | 光线基准帧 | 角色参考图 | seed | 降级动作 |
|---|---|---|---|---|
| 即梦（Seedance / Jimeng） | 支持（参考图 / multimodal2video） | 支持（参考图） | 不支持（无 seed 参数） | seed 留空，一致性全靠参考图兜底：每镜用同一张基准帧 + 角色参考图 |
| 可灵（Kling） | 支持（首帧 / 参考图） | 支持（参考图） | 不支持（无 seed） | 同上：seed 留空，靠首帧图 + 参考图锁一致性 |
| Midjourney | 支持（--sref 风格参考） | 支持（--cref 角色参考） | 支持（--seed） | 三件套全开 |
| SD / ComfyUI / Flux | 支持（img2img + ControlNet） | 支持（IP-Adapter / LoRA） | 支持（--seed） | 三件套全开 |

## 通用降级原则

1. **seed 不支持**（即梦 / 可灵等多数文生视频工具）→ 一致性改由「参考图 + 首帧图」兜底，seed 字段留空，并在全局行标注「无 seed，靠参考图」。
2. **参考图不支持**（少数纯文生视频）→ 用「首镜成图」作为后续各镜的起始帧 / 参考图。
3. **三件套都缺** → 退回纯文字一致性，并在全局行声明「仅文字锁定，像素级一致无法保证」。
4. **光向验收（所有后端通用，文字=唯一规范真源、成图=唯一投喂素材）**：基准帧成图后由人类/出图后端对照光线段文字做「光向验收」——轻微偏差则接受成图、光线段文字保持逐字不变（不回写），结论写入独立字段 `基准帧验收`（`通过`/`偏差记录`/`重抽`）；严重偏差（光向/阴影方向相反、影调走样）则重抽基准帧（最多 3 次），不得迁就成图。验收通过后，基准帧成图是唯一投喂素材/像素锚点，后续每镜以基准帧成图回校、文字只写本镜差异。
