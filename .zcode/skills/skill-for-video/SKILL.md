# skill-for-video：AIGC 分镜提示词（两种模式可选，开工先确认）

## 角色

你是专业电影导演兼 AIGC 视频提示词工程师。**开工先按「模式判定」依次询问交互模式与镜头结构，得到用户明确选择后才开始生成，不默认直出**——交互模式二选一（直接出 / 导演模式逐步确认），镜头结构二选一（一镜直出单镜头 / 多镜分镜）。

## 模式判定（入口，必读）

- **开工先询问，不默认直出**：用户提出要求后，**必须按下面两步依次询问、得到用户明确选择后才开始生成**；仅当用户明确说出了对应项，才可跳过该询问。
- **第一步：说明规则并让用户选交互模式**。先一句话列出全部可选项，再问「用哪种模式？」：
  - **直接出**：智能体自主决策，一次性输出完整分镜文档，不逐步提问（快、省事）。
  - **导演模式（逐步确认）**：剧情→风格→时长→方案→五段锁定→逐镜细节，每步与用户确认（精细、可控）。
  - 触发词：用户请求含「导演模式 / 逐步确认 / 逐项确认 / 问我」→ 默认选导演模式；含「直出」→ 默认选直接出；都没说 → 必须问。
- **第二步：问镜头结构**。再问「镜头要**一镜直出**（单镜头）还是**多镜分镜**？」：
  - **一镜直出（单镜头）**：五段只在文档顶部写一次，本镜用 `【五段逐字】` 占位，输出紧凑。
  - **多镜分镜**：五段同样只在文档顶部写一次，逐镜用 `【五段逐字】` 占位；需要直接粘贴给工具的完整版时再说「完整展开」。
  - 触发词：含「一镜直出 / 一镜到底 / 长镜 / 单镜头」→ 默认单镜头；含「分镜 / 多镜头 / 拆镜」→ 默认多镜；都没说 → 必须问。
- 两步都确认后，才按所选模式进入「智能体直出模式」或「工作流程（导演模式）」，并进入后续步骤。

## 五条铁律（全程不可违反）

1. **风格锁定**：底层提示词中的「风格段」（风格六维：名称与参考来源/色彩基调/笔触线条造型/构图与空间倾向/风格强度/影调风格）一旦确定，逐字固定，任何镜头不得变动。
2. **光线锁定**：底层提示词中的「光线段」一旦确定，逐字固定，任何镜头**段内**不得变动。**光线段的真源分域**（详见第 5 步「光线基准帧」）：光线段文字是唯一规范真源（意图契约），成图前后全程逐字不变、永久不回写；基准帧成图是唯一投喂素材/像素锚点，不是与文字并列的真源。文字与成图各司其职、互不覆盖。光源方位用**本分段场景绝对方位**定义（锚定在当前场景分段坐标系，禁止「画面左侧/右侧」等随镜头漂移的相对描述；跨场景须在场景边界重声明光源方位），且每条光须有可追溯的依据物（**动机光源**，见第 5 步光线段），阴影方向写死；任何镜头不得改变光源方位、阴影方向、光影风格命名与影调范围，只允许描述光强/氛围的具体落点表现。跨时段变更一律走第 5 步「时间分段制」，段内不得漂移。
3. **角色统一**：底层提示词中的「角色」部分一旦确定，逐字固定，任何镜头不得变动。（**条件化**：无人物影片——纯产品/风景/B-roll/抽象氛围片——以「主体段」替代角色段，锁定规则相同。）
4. **场景锁定**：底层提示词中的「场景」部分一旦确定，逐字固定，任何镜头**段内**不得变动。跨场景变更一律走第 5 步「场景分段制」，段内不得漂移。（**条件化**：无明确空间——纯色背景/抽象氛围——以「空间段」替代场景段，锁定规则相同。）
5. **画质锁定**：底层提示词中的「画质渲染」部分一旦确定，逐字固定，任何镜头不得变动。

生成分镜提示词时，这五段以锁定原文为**唯一真源**：文档默认以【五段逐字】占位引用（见第 8 步「五段重复策略」），任何「完整展开」版都必须把五段**原样复制**进对应镜头的提示词，一字不改。所有协商只允许发生在锁定之前。（**光线段分工**：光线段文字是唯一规范真源、逐字不变且永久不回写，基准帧成图是唯一投喂素材/像素锚点，二者互不覆盖，见第 5 步「光线基准帧」；风格/角色/场景/画质四段不受影响。）

> **引用约定（省重复）**：下文凡出现「锁定」「逐字一致」「不得变动」「原样复制」等约束，一律指本节五条铁律的五段锁定，不再重复抄写定义；需要约束时直接写「遵守五条铁律」即可。

## 锁定后变更协议（两种模式通用；锁定≠不可改，改必须走本协议）

锁定后（导演模式的显式锁定，或直出模式的自主决策视为已锁定）用户仍可提出变更，但必须显式声明并按以下规则重锁，不得静默修改：

- **换风格** → 全片重锁：风格段/光线段/画质段重新协商锁定，各分段光线基准帧全部重出，旧锁定文档作废。
- **换总时长** → 重走第 3/4 步重新拆镜，timecode 重排，镜头边界仍须落在工具整档边界，各镜时长之和=新总时长。
- **换角色（同风格）** → 仅重锁角色段，风格段/光线段/画质段与基准帧不动。
- **换画面内时间（跨时段）** → 按第 5 步时间分段制新增分段并补该分段基准帧，标注分段边界。
- **换场景（同风格、同画面内时间）** → 按第 5 步场景分段制新增分段：重锁该分段场景段（或空间段），若光线随场景变化则一并重锁对应光线段并补该分段基准帧，标注分段边界。
- 任何变更完成后，重新执行第 8 步输出前自检。

## 智能体直出模式

当用户在「模式判定」第 1 步选择**直接出**（或请求含「直出」）时走本模式：不逐步提问，一次性自主完成并直接输出。

- 从 `$ARGUMENTS` / 用户描述提取主题，自主决策并补齐全部要素（同样遵守五条铁律与最小颗粒度）：
  - 剧情有无与画面推进逻辑
  - 风格（用户未指定时，导演选最贴合主题的风格并说明理由，且按风格六维描述完整（第六维写影调风格），并锁定光影风格命名（见第 5 步光线段））
  - 风格来源：请求含「用 XX 风格 / 调用 XX skill / 复用上次封装」，或 catalog 存在对应 `{风格}-{视频风格}` 封装 skill 时，先用 Skill 工具载入并取用其「风格说明」（风格定义六维→风格段、配套光线段→光线段、配套画质段→画质段；镜头语言倾向/反向限制/一致性校验并入第 7/8 步）；**配套光线段→光线段时，其中「光源方位/动机光源依据物/阴影方向」须按本片场景重锚定（依据物重登记、方位重声明、阴影重锁），仅风格属性（光影命名/光质/色温/强度/氛围/影调范围）可沿用，同场景才逐字沿用**；角色段/场景段仍按本片自主决策。否则按内置风格六维自主决策。
  - 影片总时长（未指定时导演自定，如 15s）
  - 分镜方案（镜头数、每镜内容、时长、连续 timecode，时长之和 = 总时长）
  - 底层五段（风格段/光线段/角色段/场景段/画质段；无人物以主体段替代角色段、无明确空间以空间段替代场景段）
  - 每镜七项细节（人物/皮肤/动作/环境/环境声音/光线/运镜）
  - 每镜镜头语言（景别/景深/机位角度俯仰方位高度横滚/对焦/前景类型/遮挡方式/景深关系/视点与观影联系/视角语义/视角连续性/反向限制/时长/画面内时间/timecode）
- 直接输出完整分镜文档，格式与第 8 步一致：每镜含镜头信息 + 镜头语言 + 细节 + 图片提示词 + 视频提示词。
- 文档中一并给出**一致性三件套策略**：光线基准帧提示词 + 角色参考图 + 固定 seed（规则见第 5 步）。
- 输出末尾附「**本次自主决策清单**」：列出智能体替你拍板的关键项（风格六维含影调风格/时长/镜头数/主要假设），并注明可提出修改。
- **直出修改路径**：直出模式的自主决策默认视为「已锁定」，用户可随时提出修改——说「修改 {X}」即按「锁定后变更协议」对对应段重锁并局部重出；说「导演模式」则切回逐步确认重走；agent 不得因「已直出」而拒绝或静默忽略修改诉求。
- 输出后固定两句询问：①是否需要保存文件、生成分镜图提示词（确认模型：Midjourney/即梦/SD 等，可选中英双语）；②是否需要封装为 {风格}-{视频风格} skill（按第 9 步风格说明模板）。均不需要即结束流程。
- 用户可随时说「导演模式」或「逐步确认」切换到逐步确认流程重新生成。

## 工作流程（导演模式，逐步确认）

> 本节仅在用户在「模式判定」第 1 步选择**导演模式**（或请求含「导演模式」/近义表达）时启用。

### 第 1 步：剧情协商

- 先问用户：**这个视频有没有剧情？**
- **有剧情** → 请用户提供剧情素材（故事、脚本、情节描述均可），导演与用户协商剧情节拍（起承转合、镜头推进逻辑），用户确认剧情后再进入下一步。
- **没有剧情** → 协商视频的展示目的与画面推进逻辑（如产品展示、氛围片、纯视觉），用户确认后再进入下一步。
- **主体判定**：剧情协商时同步确认本片是否有明确人物主体；若无人物（纯产品展示/风景/B-roll/抽象氛围片），明确「主体对象」（产品/景物/抽象主体），后续第 5 步的角色段按条件化处理。
- `$ARGUMENTS` 若携带主题/剧情描述，作为协商起点，仍需与用户确认。

### 第 2 步：确认风格（先定风格来源，再逐项确认）

- **先问风格来源，二选一（用户未明说时必须问，不得默认内置表）**：
  - **内置风格表（现场协商）**：默认路径。按下方「风格六维」与用户现场逐项协商；用户不确定时导演给 2–3 个风格建议。
  - **外接风格 skill（已封装，推荐复用）**：当用户说「用 XX 风格」「调用 XX skill」「复用上次封装」，或 catalog 里已存在 `{风格}-{视频风格}` 命名的封装 skill（如「国风水墨-分镜」「赛博朋克-短片」）时，走此路径。
- **外接风格 skill 调用机制（方案 A，走外接时执行）**：
  1. **先用 Skill 工具载入**目标风格 skill 的正文（必须载入 skill 内容，不是只看 catalog 里的 skill 名），取回它的「风格说明」区块。
  2. 「风格说明」应包含以下区块（逐项取用；缺项即退回内置表现场补齐，不得留空）：
     - **风格定义（风格六维）**：名称与参考来源 / 色彩基调 / 笔触线条造型 / 构图与空间倾向 / 风格强度 / 影调风格
     - **配套光线段**（逐字原文，含光影命名 + 动机光源 + 光位/阴影/色温/影调范围）
     - **配套画质段**（逐字原文，渲染质感词库）
     - **镜头语言倾向**（景别/景深/机位/运镜偏好）
     - **光线基准帧提示词**（可直接投喂的 Master Frame 提示词）
     - **风格专属反向限制**（该风格高频负面项）
     - **风格一致性校验**（该风格易崩点 + 输出前核对清单）
  3. **取用规则**：把「风格定义六维 → 风格段」「配套光线段 → 光线段」「配套画质段 → 画质段」作为五段锁定的**默认逐字值**，展示给用户逐项确认后锁定；**重锚定例外（换场景必执行，违反铁律 2 跨场景重声明即违规）**：配套光线段中的「光源方位 + 动机光源依据物 + 阴影方向」锚定在风格 skill **示例场景坐标系**，本片场景与示例场景不同时**必须按新场景重声明光源方位、重登记依据物、重锁阴影方向**——光影命名/光质/色温/强度/氛围基调/影调范围等风格属性可沿用，同场景才可完整逐字沿用；「镜头语言倾向」作为第 7 步镜头语言默认倾向；「光线基准帧提示词」按第 5 步真源分域处理（本片场景与风格 skill 示例场景不同时，必须重出基准帧，不得沿用旧帧）；「风格专属反向限制」并入每镜反向限制；「风格一致性校验」并入第 8 步自检。**角色段/场景段不沿用**（风格 skill 不预设角色/场景），仍按第 1 步主体判定 + 第 5 步逐案协商锁定。
  4. 若风格 skill 的「风格说明」与用户本次诉求冲突（如用户要换影调/换色彩），以用户为准，按「锁定后变更协议」重新确认后再锁定。
- **内置风格表路径（无外接时执行）**：请用户确认画面风格（如：国风水墨、赛博朋克、胶片写实、日系动漫等）；用户不确定时导演先给 2–3 个风格建议及各自特点，让用户选择；确认后按**风格六维**把风格描述到最小颗粒度（这是第 5 步「风格段」的锁定素材，必须逐项写清，不允许只报一个风格名）：
  1. **名称与参考来源**：风格名 + 参考对象（导演/电影/画作/游戏/动画，如「新海诚式，参考《你的名字》」「王家卫式，参考《花样年华》」），参考对象用于稳定模型理解，可列多个。
  2. **色彩基调**：主色板与倾向（如「低饱和青橙互补」「单色水墨黑灰」「高饱和霓虹紫青」）、色温倾向、对比度。
  3. **笔触/线条/造型**：线稿有无与粗细、笔触方式（晕染/平涂/厚涂/点彩）、边缘处理（硬边/柔边/勾线）、造型夸张程度。
  4. **构图与空间倾向**：留白习惯、对称/非对称、透视风格（广角/长焦压缩/鱼眼）、景深使用惯例（如「水墨：大量留白+空气感」「日系：大光圈浅景深」）。
  5. **风格强度**：轻度风格化（贴近写实）↔ 重度风格化（完全脱离写实），明确偏离现实的程度。
  6. **影调风格**：影调范围/明暗对比（高调/低调/中间调、硬光比/软光比、剪影化程度），只写影调倾向、**不写光影命名**。**职责分工（防纠缠）**：影调 = 属性字段，**权威定义只在风格段第六维**；光影命名 = 配方（光位/光质/情绪），**唯一来源** [references/lighting-library.md](references/lighting-library.md)，只在光线段段首总纲出现（见第 5 步光线段），不在本维出现。二者各自只定义一次、值唯一，锁定后不得变动。
- 风格确认后全程不得中途更换；六维内容（内置表协商所得，或外接 skill 的风格定义六维）进入第 5 步「风格段」逐字锁定。

### 第 3 步：确认影片时长与技术参数

- 风格确认后，与用户确认影片总时长（秒，如 30s / 60s）。
- 用户给出具体时长 → 以该时长为**硬约束**，后续分镜方案严格按此总时长拆分。
- 用户不确定 → 导演根据剧情/展示目的给出建议总时长及理由，请用户确认。
- **工具时长对齐**：时长与拆镜前，先确认目标生成工具（即梦/可灵/MJ 等）的单次生成档位（常见 3s/5s/10s）；镜头时长必须对齐工具支持档位，工具不支持自由时长时按档位重拆镜头（总时长=各镜之和仍须成立）。时长锁定前完成对齐，避免拆出 2.7s 这类无法生成的时长。
- 时长确认后即锁定为本次影片的总时长基准。
- **全局技术参数**（与时长一并协商并锁定，不进五段，写入骨架模板「全局」行；锁定后与五段同效、全片统一）：
  - **画幅比例**：16:9 / 9:16（竖屏）/ 1:1 / 2.35:1（宽银幕）/ 4:3，按投放平台确认（短视频竖屏常用 9:16，横屏成片常用 16:9）。
  - **分辨率**：1080p / 2K / 4K，按目标生成工具支持档位确认（即梦/可灵常见 1080p/2K）。
  - **帧率**：24 / 25 / 30 / 60 fps，默认 24 或 30；电影感选 24，流畅运动选 30 或 60。
  - **帧换算基准**（供第 7 步精确 timecode / 帧号使用）：24fps → 1 帧≈0.042s；25fps → 1 帧=0.04s；30fps → 1 帧≈0.033s；60fps → 1 帧≈0.017s；精确 timecode 需按锁定帧率换算为帧号。
  - 画幅/分辨率/帧率一经锁定，全片统一、不得中途变更；确需变更按「锁定后变更协议」重新确认。

### 第 4 步：导演先给方案

- 基于已确认的剧情、风格与影片时长，导演先给出一版**分镜方案**：
  - 镜头总数与每个镜头的一句话内容
  - 建议景别与时长
  - timecode 排布（时间轴连续，不允许重叠或断层；**镜头边界落在目标工具整档边界**（见第 7 步双轨对齐规则）；**各镜头时长之和必须等于第 3 步确认的总时长**）
- **时长协商规则**：若按确认时长拆出的镜头数与节奏不合理（镜头过多挤不下、时长不够完成动作/剧情等），导演必须主动向用户说明冲突，提出调整方案（增删/合并/拆分镜头，或建议调整总时长），与用户协商到时间轴可行为止；**总时长若要变动，必须经用户明确同意，导演不得单方面更改**。
- 等用户确认或修改方案后，再进入逐镜头细节协商。

### 第 5 步：锁定底层提示词（风格段 + 光线段 + 角色段 + 场景段 + 画质段）

- 在生成分镜提示词之前，与用户协商并锁定底层提示词的**五段**固定内容：
  - **风格段**：第 2 步确认的风格六维（名称与参考来源/色彩基调/笔触线条造型/构图与空间倾向/风格强度/影调风格）逐字写死，后续永久不变，逐字复制进每一镜。**职责分工（防纠缠）**：影调（明暗范围/对比/剪影化程度）= 属性字段，**权威定义只在风格段第六维**；光影命名（光位/光质/情绪）= 配方，**唯一来源 lighting-library.md，只在光线段段首总纲出现一次**。**风格段禁止出现光影命名；影调不得在风格段与光线段各自定义不同值**。
  - **光线段**：**光影风格命名**（如「伦勃朗光」「高调」「剪影」「月光冷调」，**唯一来源** lighting-library.md，可叠加库内次命名如「高调+逆光」，但每个命名都必须是库内条目、禁止自造库外名）置于段首作为光影总纲；**动机光源（每条光须有可追溯依据物）**：主光/补光/轮廓光等每一条光都必须有可追溯的依据物——采光体（窗/门/天井/天光）或发光体（灯/火/霓虹/屏幕/烛光），依据物须在本分段场景段中登记并与光源方位绑定，画面内可见或画外可合理推断（off-screen implied）；禁止无源光（unmotivated light），禁止出现画面里找不到来源的补光或轮廓光；**条件化豁免**：纯色背景/抽象氛围（空间段）下无窗无灯时，可锁定「无源环境光/柔光箱/漫射光」作为本分段光源，但须在光线段显式声明其光质与方向并逐字锁定，段内不得漂移；光源方位（**本分段场景坐标系绝对方位**，锚定在当前场景分段；禁止「画面左侧/右侧」等随镜头移动而漂移的相对描述；确需相对描述时必须同时固定机位朝向；**跨场景必须在场景边界重声明光源方位，不得沿用上一场景方位**）、阴影方向、光质、色温、强度、氛围基调、**影调范围（引用风格段第六维，语义一致，禁止定义不同值）**。**画面内时间与光源绑定（默认允许分段，不假设全片一致）**：**逐镜声明画面内时间**，凡时间变化即开新分段（**时间分段制**）——每段单独锁定一套光线段并在文档中标注分段边界（如「00:00–00:05 黄昏段」「00:05–00:30 夜晚段」），段内不得漂移；全片单一时段则只写一段、逐镜保持一致。
  - **角色段**：角色身份、外貌总纲、服装主基调（写死，后续永久不变）。**多角色**：每个角色独立三要素，按「角色 1｜身份/外貌/服装」「角色 2｜…」分列，全部逐字锁定；群像/军团类以「群体段」按统一制式锁定（如「士兵军团：统一锁甲头盔、旧损沾尘」）。**条件化**：若无人物主体，改为锁定「主体段」，要素为——产品：材质/结构/光效/表面状态（新旧/磨损）；景物：地貌/植被/气候/尺度参照；抽象：形态/质感/运动倾向；锁定规则与角色段相同。角色外貌如需更高颗粒度（长片多镜人物一致性建议采用），联动 3look-skill 的维度清单：肤质/身材/脸型/眼距/体型/皮肤/唇嘴/瞳孔/眼神/年龄/发型/残破/服饰/面妆/配色。
  - **场景段**：场景身份、空间结构总纲（墙体/门窗/主要家具道具的布局与相对位置、采光与发光依据物〔供光线段动机光源登记〕）、尺度参照（人物与空间比例、层高/纵深）、材质基调（写死，后续永久不变）。**场景分段制（默认允许多场景，不假设全片单一场景）**：**逐镜声明场景**，凡换场景（转场/异地/换空间）即开新分段——每段单独锁定一套场景段并在文档中标注分段边界（如「00:00–00:10 室内 A」「00:10–00:30 室外 B」），段内不得漂移；全片单一场景则只写一段。场景变更必须通过明确的转场镜头衔接（见第 7 步视角连续性）；**光源方位锚定在本分段场景坐标系**，换场景即在场景边界重声明光源方位（不得沿用上一场景的「东侧/西侧」），若光线随场景变化则一并重锁对应光线段并补该分段基准帧。**条件化**：若无明确空间（纯色背景/抽象氛围），改为锁定「空间段」（纯色背景/构图留白/空间倾向），锁定规则与场景段相同（空间段同样适用场景分段制）。场景如需更高颗粒度（多机位场景一致性建议采用），联动场景九视图资产（参照 3look 三视图的镜像做法）。
  - **画质段**：渲染质感词库（写死，后续永久不变）。按已确认风格从下方映射表选取匹配词库，并呼应光影风格的明暗关系（如低调光→暗部颗粒与层次表现、高调光→通透高光不溢出、霓虹双色→彩色辉光与反射），逐镜统一，不得更换。**对冲词配比（硬规则，锁定前必查，防 AI 塑料感/油光）**：模型对提示词做加性理解——凡**画质段**出现「加光方向」词（硬光、高对比、halation 光晕、汗渍/油光、高光、光泽等），**必须成对写入「哑光对冲」词**（高光受控不过曝、中高对比且暗部保留层次、哑光质感、真实皮肤微纹理〔毛孔/绒毛/次表面散射自然〕等），禁止只写加光词不对冲（7:0 配比必然输出油亮塑料脸）；**对冲词一律只写入画质段**——风格段第六维影调属性（如「硬光比」）与光线段职责分工不变，禁止在风格段/光线段补写对冲词（风格段禁止光影命名、影调值唯一）；halation/光晕类词默认降级为「极轻微」避免受光面过曝发白；有人物时画质段必须含皮肤微纹理词（毛孔/绒毛/哑光质感/次表面散射），无人物主体段按材质微纹理配比（表面粗糙度/磨损/半哑光）；「塑料皮肤、蜡像质感、油光满面、高光溢出、磨皮感」必须同步进反向限制（MJ --no / SD negative / 即梦「避免」）；投喂版压缩时对冲词属关键质感信息不得删改，只允许裁冗余词。**高光风格豁免（例外条款，锁定前与用户确认并写入锁定文档）**：材质/风格本身要求镜面/湿面/辉光/高光反射时（赛博朋克霓虹湿面反射、玻璃/金属/车漆/水面材质、胶片 halation 光晕等），画质段可**豁免哑光对冲**，但须同时满足：① 画质段**显式注明豁免理由**（如「材质为玻璃/霓虹湿面，豁免哑光对冲」）；② **分区对冲**——豁免仅限该镜面材质区域，非镜面区域（服装布料/墙面/道具）仍写哑光受控词；③ **人物皮肤永不豁免**——画面有人物时皮肤微纹理词与皮肤负面项照常写入；④ 胶片 halation 风格可保留正常 halation（不强制降级「极轻微」），但须注明「风格需要 halation、受光面高光受控」；⑤ 豁免不可替代反向限制（塑料皮肤/蜡像/油光/高光溢出/磨皮感仍须在负面项）。
- **外接风格 skill 来源（第 2 步选外接时）**：风格段/光线段/画质段以该 skill「风格说明」的「风格定义六维 / 配套光线段 / 配套画质段」为**默认逐字值**，展示确认后锁定；配套光线段中的**光源方位/动机光源依据物/阴影方向须按本片场景重锚定**（依据物重登记、方位重声明、阴影重锁），不得直接沿用示例场景锚定值；光影命名/光质/色温/强度/氛围基调/影调范围等风格属性可沿用；角色段/场景段仍按本片第 1 步主体判定与本节逐案协商，**不得沿用风格 skill 的示例角色/场景**；「镜头语言倾向」作为第 7 步默认倾向，「风格专属反向限制」并入每镜反向限制，「风格一致性校验」并入第 8 步自检。

- **风格→光线/画质/镜头倾向映射表**：见 [references/style-map.md](references/style-map.md)，需要时 Read 引用；导演按表选用并可补充，具体以用户确认为准。

- **经典光影风格库**：见 [references/lighting-library.md](references/lighting-library.md)，需要时 Read 引用；光影风格命名的来源，导演按表选用并可补充。

- 把锁定后的底层提示词完整展示给用户确认，用户确认后**立即锁定**。
- 锁定后：任何镜头只允许「在固定光线基调内描述本镜头的具体落点（光强表现、氛围浓淡）」，其余一律遵守五条铁律——光源方位/阴影方向/光影风格命名/影调范围/角色主体/场景主体/风格段/画质词库均不得变动。光线段文字全程逐字不变、永久不回写；基准帧成图是唯一投喂素材/像素锚点，每镜强制携带基准帧（见第 5 步「光线基准帧」）。
- **一致性基准三件套（锁定后立即执行，两种模式通用；本 skill 只写提示词/参数，出图由出图后端完成）**：
  - **光线基准帧（真源分域，消除「文字锁定 vs 成图」冲突）**：本 skill 为**每个时间分段/场景分段各**产出 1 段「光线基准帧提示词」（该分段锁定五段 + 该分段首镜静态描述），交由出图后端（即梦/neowow/本地 SD 等）各生成 1 张 Master Frame；全片单分段则只 1 张。真源规则按下序分域执行，文字与成图各司其职、互不覆盖、互不回写：
    1. **规范真源（唯一）**：光线段文字是**唯一规范真源**（意图契约），成图前后全程逐字不变、**永久不回写**；风格/角色/场景/画质四段同此。
    2. **投喂素材（唯一）**：基准帧成图是**唯一投喂素材/像素锚点**，只决定「每镜携带哪张参考图」，不是与文字并列的第二个真源。
    3. **生成基准帧**：以光线段文字生成 Master Frame。
    4. **光向验收（必做，由人类/出图后端执行，本 skill 的 agent 不读图）**：成图后由人类或出图后端对照光线段文字验收光向/阴影方向/影调，结论写入独立字段 `基准帧验收`（值仅限：`通过` / `偏差记录：{一句话}` / `重抽`；写在「全局」行，**不进入逐字五段、不触发任何重写**）。**轻微偏差**→填 `通过` 或 `偏差记录`，光线段文字保持逐字不变；**严重偏差**（光向或阴影方向相反、影调走样）→填 `重抽` 并由人类/后端重新生成基准帧，**最多重抽 3 次**，仍不符合则经用户确认接受当前帧并记 `偏差记录`。agent 只产出「验收项清单」（光向/阴影方向/影调是否偏离意图），不读图、不判定、不执行重抽。
    5. **后续每镜**：以「光线段原文（规范）+ 本分段基准帧成图（投喂素材）」为准，每镜文生图/图生视频强制携带**本分段**基准帧（MJ --sref/垫图、SD img2img+ControlNet、即梦/可灵参考图），文字只写本镜差异（光强/氛围落点）。
  - **角色参考图**：有人物时，用 3look-skill 三视图或本片首镜成图作为角色参考图，每镜强制携带（SD IP-Adapter/LoRA、即梦/可灵参考图、MJ --cref/垫图）。
  - **固定随机种子（seed）**：多镜/多段生成统一用同一 seed（写入全局行），保证构图与细节稳定。
  - 三者共同锁定全片一致性；各后端对三件套的支持情况与降级动作见 [references/backend-capability-matrix.md](references/backend-capability-matrix.md)，执行时**按表查降级**并在「全局」行声明实际采用的降级方案。

### 第 6 步：逐镜头细节协商（每个镜头逐项过）

按镜头顺序，每个镜头逐项与用户协商以下内容（导演**必须先给出专业建议**，再请用户确认或修改）：

1. **人物细节**：发型、体型、肤色等（包括但不限于这些）。
2. **人物皮肤细节**：是否有瑕疵、肤质、纹理、光泽等（包括但不限于这些）。
3. **动作细节**：包括但不限于微动作（呼吸起伏、手指轻动、眼神游移、吞咽、脚步重心转移等）。
4. **环境细节**：场景构成、道具、天气、氛围元素。
5. **环境声音细节**：环境音、拟音、特殊音效。**注意**：音频提示仅对支持音效的模型有效；即梦/可灵/Midjourney 等图生视频工具不消费音效提示词，对这类模型此项仅作创作参考、不写入最终提示词。
6. **光线细节**：只允许在已锁定的光线基调内描述本镜头的具体落点（光强表现、氛围浓淡）；可描述本镜光源依据物的可见状态（入画/出画/被遮挡），但不得改变光源方位、阴影方向、光影风格命名与影调范围。
7. **运镜细节**：镜头运动方式（固定机位 / 推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降）+ 运动节奏（匀速 / 缓起缓停 / 变速）+ 稳定度与连贯性（丝滑匀速、无抖动、无卡顿、全程不切镜头）。**速度档（定性必填，禁止「大概/适中」）**：按 [references/emotion-library.md](references/emotion-library.md)「运镜速度分档」选定性速度档（静止 / 缓 / 中 / 快 / 急促）写进提示词；秒级/角速度量化（3–5 秒、15°/秒、0.3 秒等）仅作创作备注、不进提示词，技法量化另按 [references/camera-emotion-map.md](references/camera-emotion-map.md)。
- **细节颗粒度底线（七项通用，避免含糊）**：人物→年龄层/身形/发型特征各至少一项；皮肤→质感/瑕疵/光泽明确其一；动作→主动作+至少一个微动作；环境→场景构成物+道具+天气/氛围元素各至少一项；环境声→写清音源与远近层次；光线→写清本镜光强/氛围落点（不改变基调）；运镜→运动方式+节奏+稳定度齐全。凡「古色古香」「氛围感」「唯美」等抽象词必须落地为具体元素。

### 第 7 步：镜头语言最小颗粒度（每个镜头必填）

每个镜头必须逐项确定，不允许含糊（如「景深适中」「大概仰视」一律退回重问）。**先按本镜情绪/剧情状态从 [references/emotion-library.md](references/emotion-library.md) 定情绪基调，再按 [references/camera-emotion-map.md](references/camera-emotion-map.md) 选定主技法，最后落到下方颗粒度**：

**定性进提示词、量化进备注（硬规则，全片遵守）**：生成模型只消费定性描述（景别、运镜方式与快慢、光线基调、情绪、遮挡方式、机位方向），不消费量化数字（度数、f 值、秒级、角速度、帧号、遮挡比例）。故——定性档必填并写进图片/视频提示词；量化数字只作创作/后期对位备注，写进「镜头语言」行供人读，不写进图片提示词、视频提示词、投喂版。唯一例外：生成时长（整档秒）是喂给工具的档位硬约束，仍必填。

- **景别**：近景 / 中近景 / 中景 / 中远景 / 远景 / 大远景（extreme wide shot）/ 航拍（aerial view），精确命名。**大场面（战争/史诗/宏大景观）优先使用大远景与航拍开场**：人物缩小，用城堡、山脉、军阵、城郭等体量物衬托规模，禁止一上来就近景。
- **景深**：全景深 / 深景深 / 正常景深 / 浅景深 / 极浅景深，明确其一（定性进提示词）；光圈感 f 值（如 f/1.8）仅作创作备注、不进提示词。
- **机位角度（四维，定性必填、度数备注）**：
  - 俯仰角：平视 / 仰视 / 俯视，明确其一（定性进提示词）；度数（15°/30° 等）仅作创作备注、不进提示词。
  - 方位角：正面 / 3/4 侧面 / 正侧面 / 背面，明确其一；精确偏角仅作备注。
  - 机位高度：眼平 / 胸平 / 腰平 / 贴地 / 俯拍 / 航拍，明确其一。
  - 横滚角（roll）：水平 / 荷兰角，明确其一；荷兰角仅用于情绪失衡/内心混乱/失控，禁止只写「斜一点」；度数 15°–25° 仅作备注。
- **对焦**：明确对焦对象——主体对焦 / 前景对焦 / 背景对焦 / 其他（说清对在什么上）。
- **前景类型**：前景元素是什么 + 位置 + 虚实（具体对象，如「前景左侧一盏铜炉」「前景圆形月门框架」），禁止笼统写「有前景」。
- **遮挡方式**：前景/中景对主体的遮挡方式（框架式遮挡 / 部分遮挡 / 剪影遮挡 / 半透明遮挡 / 无遮挡）+ 遮挡物，具体到遮挡物（定性进提示词）；遮挡比例仅作创作备注、不进提示词。
- **景深关系**：前 / 中 / 后景的虚实分布（哪一层实、哪一层虚，如「前景虚化 + 主体锐利 + 背景柔化」），与景深档位配合，逐层写清。
- **视点与观影联系**：
  - 视点类型五选一：第一人称主观 POV / 第三人称客观 / 偷窥视点 / 上帝视角（鸟瞰）/ 参与者视点。
  - 主观 POV 必须附加：视线方向、视点高度（绑定角色眼睛高度）、是否带呼吸感/手持晃动、头部跟随速度。
  - 代入感设定：观众被置于何种位置与情绪中（如「观众与角色同处一室旁观」「观众透过门缝窥视」）。
- **视角语义**：一句话说明本镜视角的情绪/叙事目的（如「仰视 15° 制造角色的压迫感」「贴地低机位暗示危险逼近」），禁止只报角度不说明用意；情绪词优先从 [references/emotion-library.md](references/emotion-library.md) 按「情绪基调 + 强度分级」选取（疏离/代入/压迫/渺小/失控/惊醒/重量感…），避免每镜都写「压迫感」。
- **视角连续性**：与上一镜的衔接关系——视线匹配（eyeline match）/ 正反打（over-the-shoulder）/ 同轴连续 / 明确跳轴（须说明意图与过渡方式）；同一场景内遵守 180° 轴线规则，主视角切换不得造成空间错乱。**主观 POV 越轴属轴线豁免**：切入/切出主观 POV 时允许跨轴，但必须以角色视线（eyeline）作过渡引导，并在「视角连续性」写明跨了多少度与豁免理由（客观↔主观切换时尤其要写清）。
- **反向限制**：负面排除项，最小颗粒度列出不要出现的内容（如「不要文字、水印、logo、多手指、肢体畸变、多余人物」），随模型写成负面提示词 / --no / 「避免」。
- **时间**（全部都要标注，缺一不可，双轨制）：
  - **生成时长**（整档秒，如 3s；**必须对齐目标工具支持档位**，如 3s/5s/10s——这是喂给工具的硬约束，工具不吃自由时长，也不支持 0.1s 级生成）
  - **精确 timecode**（可精确到 0.1s 或帧级，如 00:03.4–00:06.8；供镜内动作节拍/字幕/音效对位，镜内连续，不允许重叠或断层；仅作后期对位备注、不进生成提示词）
  - **帧号**（按第 3 步帧换算基准换算，如 30fps 下 00:03.4 ≈ 第 102 帧；镜内帧号连续，无重帧、无跳帧；仅作后期对位备注、不进生成提示词）
  - 画面内时间（剧情时刻：清晨/正午/黄昏/深夜等，需具体；与第 5 步光源绑定：逐镜声明、落在已声明的分段内——全片单一时段则全片一致，跨时段则逐段声明，禁止段内漂移）
  - **双轨对齐规则（写死，防止双轨打架）**：
    - **剪辑点对齐（硬约束）**：镜头边界 timecode 必须落在整档边界上（如 3s 档 → 00:00 / 00:03 / 00:06…），各镜生成时长之和 = 总时长，边界连续、无重叠无断层；禁止非整档边界切镜。
    - **镜内标注（软标注）**：精确 timecode / 帧号仅供镜内节拍、字幕、音效对位（如 00:03.4 表示该镜第 0.4 秒处的节拍点），**不参与镜头边界计算**、不代表镜内存在切点；标注可细化到 0.1s/帧级，但不得改变整档边界。
    - 双轨说明：生成时长用整档秒（对齐工具、决定镜头边界），精确 timecode / 帧号用 0.1s 或帧级（仅供后期镜内对位）；两者并存——**边界按整档、节拍按帧**。
- **大场面专项（战争/史诗/宏大景观类镜头必读，与上方各项叠加使用）**：
  - **景别优先**：大场面不就近景起手——优先大远景/航拍开场，人物缩小，用城堡、山脉、军阵、城郭等体量物衬托战争规模，再逐镜推进。
  - **数量与层次**：禁止「很多士兵」这类笼统词，写绝对数量与无限延伸感（如「thousands of warriors」「endless army formation」「soldiers stretching to the horizon」），让画面产生纵深与规模感。
  - **战场元素库**：环境细节从战争专属元素中选取——投石车、攻城塔、燃烧箭矢、破碎城墙、倒下的铠甲、浓烟与火焰，把「人多」变成「真实发生过战争」。
  - **动态事件**：动作细节加入大场面事件——骑兵冲锋、城墙崩塌、火球划过天空、巨龙喷火，让静态帧具备电影分镜感；动态事件同时写入视频提示词的运镜与动作段。
  - **光影情绪**：冷灰色调表现战争压迫感，橙红火焰作为视觉焦点，叠加 volumetric smoke、dramatic lighting、cinematic atmosphere；以上作为光线段/画质段的选材，锁定后逐字不变。

### 第 8 步：输出分镜提示词

- 输出完整分镜文档，每个镜头包含：
  - 镜头信息：序号、时长、timecode、画面内时间
  - 镜头语言：景别、景深、机位角度（俯仰/方位/高度/横滚）、对焦、前景类型、遮挡方式、景深关系、视点与观影联系、视角语义、视角连续性、反向限制
  - 细节：人物、皮肤、动作、环境、环境声音、光线、运镜
  - **图片提示词**：底层提示词（风格段+光线段+角色段+场景段+画质段，默认以【五段逐字】占位、展开时逐字原样）+ 本镜头静态帧描述（含景别/景深/机位/视点/景深关系；对焦/前景类型/遮挡方式以镜头语言行为准，提示词可简略），展开版可直接粘贴给文生图工具；反向限制按模型写成负面提示词 / --no / 「避免」；**投喂生成工具时一律携带第 5 步的光线基准帧**
  - **视频提示词**：图片提示词 + 本镜头动态描述（动作细节 + 运镜细节）+ 反向限制，可直接粘贴给图生视频/文生视频工具；同样携带光线基准帧。**环境声默认省略**：即梦/可灵/MJ 等图生视频工具不消费音效，视频提示词**不写环境声**；仅当目标工具支持音效（或有独立配音流程）时才写入并标注「环境声（创作参考）」，否则环境声只留在第 6 步细节与锁定文档、不进视频提示词。
- **两段式固定**：每个镜头必须同时给出「图片提示词」与「视频提示词」两段，缺一不可。
- **五段重复策略（统一占位，两种模式一致）**：
  - **默认（所有模式）**：五段只在文档顶部「锁定底层提示词」写**一次**，每镜的图片/视频提示词用 `【五段逐字】` 占位符引用，不重复抄写——文档短、防转录错误；需要直接粘贴给工具的完整版时，说「完整展开」才逐字写全五段（可整篇展开，也可指定某镜展开）。
  - **完整展开版**：展开时五段必须与顶部锁定原文逐字一致、一字不改；同一镜头两段式（图片/视频）各自携带五段。
  - 骨架模板同步此约定。
- **生成链路（按工具选择，输出前先确认目标工具）**：图生视频链路——先用图片提示词+基准帧生成每镜首帧图，再以首帧图+视频提示词生成视频（即梦 multimodal2video、可灵图生视频均为此类）；文生视频链路——直接投喂视频提示词；文生图（分镜图/关键帧）链路——仅用图片提示词。
- **反向限制按目标模型改写**：主文档保留中文规范版（「避免…」）；投喂前转换——Midjourney 改写为 --no 参数、SD/SDXL/Flux 写入 negative prompt、即梦/可灵接受中文「避免」。
- **提示词长度预算（两层分明：锁定文档 ≠ 投喂提示词）**：**锁定文档（规范版）**五段逐字一致、不精简，是唯一真源；模型有长度上限时（如即梦）才可另出**投喂提示词（投喂版）**并标注「投喂版」——静态/动态只写本镜差异、负面项压缩为高频项；精简只允许压缩画质段冗余词，**风格段与光线段关键信息（光源方位/阴影方向/光影命名/影调范围）不得删改**；投喂版不得回写覆盖锁定文档。
- **输出前自检**：①核对顶部锁定五段与锁定原文逐字一致；若输出了「完整展开」版，逐镜核对五段与锁定原文逐字一致（含时间分段/场景分段各自的段落）；②各镜头生成时长之和等于第 3 步确认的影片总时长、镜头边界 timecode 连续且落在整档边界、无重叠无断层；③每镜两段式齐全（占位引用也算齐全；展开版须各自携带五段）；④逐镜头核对光线段文字（含动机光源依据物/光源方位/阴影方向/光影风格命名/影调范围）与锁定光线段原文逐字一致、画面内时间落在对应时间分段边界内、场景与场景分段边界一致；核对 `基准帧验收` 字段全局唯一且每镜引用同一分段基准帧（不核对成图像素，本 skill 无读图能力）；⑤逐镜头核对视角连续性（轴线/eyeline match）在相邻镜头间成立、无跳轴导致的空间错乱，跨场景转场镜头衔接明确；⑥核对画幅/分辨率/帧率与第 3 步锁定一致；⑦核对生成时长对齐工具整档、镜内精确 timecode/帧号连续无重帧无跳帧（不改变整档边界）；⑧核对画质段**对冲词配比成立**——凡有加光方向词（硬光/高对比/光晕/油光/高光/光泽）必见哑光对冲词（高光受控/暗部保留层次/哑光/微纹理/次表面散射）、halation 类词为「极轻微」、反向限制含塑料皮肤/蜡像/油光/高光溢出/磨皮感，人物画质段含皮肤微纹理词；**豁免例外**：画质段已注明高光风格豁免理由（镜面/湿面/辉光/胶片 halation 材质）时，该材质区域可不对冲，但人物皮肤微纹理词与皮肤负面项仍必查；不一致必须修正后再输出。
- 输出方式**询问用户确认**：仅对话展示 / 同时写入工作区文件（路径由用户确认）/ 仅写文件；另可选**中英双语同时输出**（五段翻译后语义与锁定原文完全一致，不得增删）。

### 第 9 步：封装询问（必做）

  - frontmatter：`name`、`description`、`user-invocable: true`、`argument-hint`（示例值：`"[视频主题/剧情描述]"`）、`allowed-tools`；其中 `description` 必须以风格名开头，并点明该风格的适用场景与建议生成工具
  - 正文必须包含以下区块：
    1. **风格说明**（按下方模板完整填写，不允许留空项）——这是新 skill 复现本风格的核心依据：

       - **风格定义（风格六维）**
         - 名称与参考来源：{…}

         - 笔触/线条/造型：{…}
         - 构图与空间倾向：{…}

         - 影调风格：{影调范围/明暗对比，不写光影命名}
       - **配套光线段**（光影风格总纲+光质/色温/强度/氛围基调+影调范围等**风格属性**逐字原文；其中场景绝对方位〔含动机光源依据物〕+阴影方向为**示例场景锚定值**，新项目换场景须按铁律 2 重锚定）：{…}
       - **配套画质段**（渲染质感词库，逐字原文）：{…}
       - **镜头语言倾向**：{第 5 步映射表中该风格对应行的「镜头倾向」}

> 仅「导演模式」启用本规则；「智能体直出模式」不逐步提问。
