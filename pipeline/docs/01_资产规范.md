# 资产规范 SOP（跨项目复用）

> 这份规范是**题材无关**的：换小说时结构不变，只换内容。
> 违反这里的任何一条，都会在下游镜头生成时以"脸漂移 / 布景对不上 / 方位乱跳"的形式暴露，
> 而那时返工成本是现在的几十倍。**资产层是唯一不能省的一层。**

---

## 〇、四条铁律（Asset-First）

1. **资产图先于分镜**：跨镜复用的角色/场景/道具，必须在写分镜前出图并锁定。
2. **"名字+装扮"不是资产**：文字描述只是索引；资产 = 可直接投喂模型的**参考图**。
3. **无图不进分镜**：分镜引用的 `@锚点` 必须指向已锁定资产图，否则阻断。
4. **分批出图 + 逐批确认**：角色 → 场景 → 道具，每批锁定后才进下一批。

## 一、角色资产

每名角色一套 **5 张**，编号 `CHR-<nn>-<角色名>`：

| 文件 | 内容 | 硬要求 |
|---|---|---|
| `CHR-01_head_front.png` | 头部正面特写 | 大比例，占画面 60%+ |
| `CHR-01_head_three_quarter.png` | 头部 3/4 侧特写 | **主要取脸来源** |
| `CHR-01_head_side.png` | 头部纯侧特写 | 用于转头/侧身镜 |
| `CHR-01_body_front.png` | 全身正面 | **必须砍掉头** |
| `CHR-01_body_back.png` | 全身背面 | **必须砍掉头** |

### 1.1 为什么全身图必须无头（关键，违反必返工）

> "远景时模型会从那张小而糊的全身图上取脸。把头去掉，模型就只剩一个地方能取脸——脸特写。"

全身图上留着一张简化正脸时，模型有**两个互相冲突的取脸来源**：
全身的脸（正面、寥寥数笔）和特写的脸（3/4、细节丰富）。
结果是远景镜头用全身那张脸、近景镜头用特写那张脸 —— **同一角色在同一集里两张脸**。

**做法**：颈部以上整体裁掉，并把画布重新向下取景（下巴以下到脚底）。
不能简单切一刀 —— 要先保证原图头顶有足够留白，否则会连着脖子一起切掉。

### 1.2 设定图必须"朴素"

- **灰底**（中性灰 #808080 附近），不要纯白：白底在抠像时边缘发虚，且与浅色衣物混淆。
- **平光**：低对比、阴影极浅的均匀照明。不要戏剧侧光、不要轮廓光。
- **不修图**：不加颗粒、不加暗角、不加电影调色。

> 原因：电影感应该由场景决定。把颗粒和电影镜头烘进设定图，
> 角色会把那套观感带进每一个场景，并且不再对新光线做出反应。

### 1.3 五官 10 项必写（写进生成提示词）

脸型骨相 / 眉形 / 眼型与眼窝 / 瞳色与反光 / 鼻梁山根 / 唇形唇色 /
下颌线与折角 / 耳廓耳型 / **标志性特征** / 面部肌肉与肤色

**标志性特征**是跨镜识别的锚，每个角色至少给一个：疤、痣、异色瞳、缺牙、发际线形状。
没有锚点的脸，换个角度就认不出是同一个人。

瞳孔必须画**高光点**（角膜反射）。没有高光的眼睛在动画里是"死眼"，
会让角色在所有镜头里显得没有生命。

### 1.4 服装材质 6 项必写

面料类别 / 编织与表面纹理 / 垂坠受力与硬挺度 / 战损污损做旧 /
金属扣具光泽 / 缝纫与剪裁工艺

### 1.5 表情差分（第二批）

主要角色另出 6 个表情头：平静 / 咬牙 / 惊 / 痛 / 冷笑 / 喊。
命名 `CHR-01_expr_<情绪>.png`。同一灰底平光、同一头部角度。

## 二、场景资产

每个场景一套 **3 张**，编号 `SCN-<场景名>`：

| 文件 | 用途 | 生成方式 |
|---|---|---|
| `SCN-xx_plan.png` | **俯视平面调度图** | **程序化绘制**（见下） |
| `SCN-xx_cams.png` | **机位调度图** | 程序化绘制 / 3D 截图 |
| `SCN-xx_hero.png` | 场景主图（3/4 视角） | 生成 |

### 2.1 平面调度图必须包含（缺一不可）

1. **场地实体块**：墙体、建筑、棚架、栅栏画成有尺寸的矩形，不能只写字。
2. **比例尺**：一格 = 1 米。
3. **人物站位点 + 朝向箭头**。
4. **动作轴线**：穿过两个站位点的连线。
5. **A/B 侧分界线**：一条**贯穿全场并延伸到框外**的实线。
   > "禁止越轴"只有标签没有线 = 这张图的核心承诺没兑现。
6. **机位占位点**：每个 CAM 带**朝向箭头 + 视锥扇形**，落在场景平面上。
   只有标签没有朝向，执行者无法判断机位在正面还是背面。
7. **锚点物编号**：柱子/门/桌/灯编号（A1、A2…），走位绑在锚点上。
   > "角色站在灯旁，面向门" 可用；"角色在房间里" 是抽奖。

### 2.2 场景主图规则

- **用 3/4 视角，不要正面**。正面"漂亮壁纸"在大远景上会变成一张平贴图，
  出了它的边界模型就开始乱编环境。
- **单一光逻辑**：一个光源、一个阴影方向。绝不能两个太阳。
  阴天漫射光虽然安全，但**没有可继承的投影方向**，多机位的光比一致性就没有依据。
  → 需要明确写一个"名义光源"（即便被云层打散），供所有机位沿用。
- **避免反射镜头**：水洼、镜面、刀刃。引擎算不清"反射体+被反射物"同框的空间。
  → 满地积水的场景，必须保证**双人机位的中轴不压在水面上**。

### 2.3 GEO 空间地图（每场戏一份，逐字复制进该场每个镜头）

只写空间，不写人物剧情：

```
GEO SPATIAL LAYOUT（全镜头锁定，纯空间地图）：
— 场地 = 泥院，横向约 6m
— 鸡棚：画面左，x≈-2.4，宽 1.9m
— 木栅栏：画面右，x≈+2.6
— 矮墙：后方 y≈5.1；瓦房两栋在 y≈6.9 / 7.2
— 锚点 A1 = 鸡棚左立柱，A2 = 栅栏中柱，A3 = 矮墙门洞
— 陈九斤：画面左，伏泥，x≈-0.8，朝右上
— 赵乾：画面右，站立，x≈+0.95，低头朝左下
— 180° 轴线 = 两人视线连线；摄像机永远停在 A 侧，绝不越线
— 名义光：右上方来光，被云层打散，全片阴影统一向右下
```

**规则**：
- 方位只从摄像机出发（"画面左/画面右"），不写"站在角色左边"。
- 位置用**地标 + 米数**。
- **每剪一刀之后，重新写一遍谁站在哪、看向哪**（模型不记得上一镜）。
- **静态对话戏只给房间的一个角落，不给整个房间**（空间越小，模型越没得选）。

### 2.4 横屏镜头的物理约束（本项目实测踩过的坑）

> **2026-09-11 规格变更**：以下竖屏数据已废止，保留作为"为什么必须反推焦距"的案例。
> **现行数据见 `04_横屏焦距与景别反推表.md`。**

~~768×1344 竖屏 + `sensor_fit=VERTICAL` 时横向传感器只有 `24×768/1344 = 13.71mm`，
**横向 FOV 极窄**：~~

| 焦距 | 横向 FOV | 可见宽度（旧竖屏，已废止） |
|---|---|---|
| 20mm | 37.8° | 8.7m 处 5.96m |
| 24mm | 31.9° | 9.6m 处 5.48m |
| 35mm | 22.2° | 7.5m 处 2.94m |
| 60mm | 13.0° | 4.0m 处 1.14m |
| 85mm | 9.2° | 3.2m 处 0.51m |

**现行（横屏 1344×768，`sensor_fit=AUTO` → 贴水平，`sensor_width=36mm`）：**

| 焦距 | 3m 处可见宽 | 3m 处可见高 | 用途 |
|---|---|---|---|
| 18mm | 6.00 m | 3.43 m | 全景带环境 |
| 24mm | 4.50 m | 2.57 m | 全场／双人全body |
| 35mm | 3.09 m | 1.76 m | 单人全身 |
| 50mm | 2.16 m | 1.23 m | 中景 |
| 85mm | 1.27 m | 0.73 m | 近景 |

→ **同一个 35mm，横屏能拍到的宽度是竖屏的 2.63 倍**（3.086m vs 1.176m @3m）。
**这才是"横屏"的真正含义：不是把画面裁宽，是同一句话能装下的信息量翻了 2.6 倍。**
竖屏时代为了把两个人塞进画面只能拉到 5 米外，脸就只剩指甲盖大——那是当时所有构图问题的总根因。

→ **场景的横向尺度必须按镜头能拍到的宽度来设计**，
否则提示词里写的布景根本不在画面里，模型只能自己编，每镜编得不一样。

→ **分镜表必须同时给出 `lens_mm / dist_m / visible_w_m` 三列**，
`visible_w_m` 由公式算出，**不许手填**。只写焦距不写距离的表，可以骗过所有人
（`08` 分镜表里 CAM1 写着 "wide"，实际 35mm 只拍 2.94m）。详见 `04_横屏焦距与景别反推表.md` 第七节。

## 三、道具资产

编号 `PRP-<nn>-<道具名>`，风格与角色一致（灰底平光、3/4 视角）：

- 关键叙事道具（如麻袋、灵石、信物）必须单独建档，因为它们在特写里会被当成主体。
- 特写用道具要标注**材质 6 项**，否则模型会渲染成塑料/水球之类的错误材质。
- 数量道具（"四百枚灵石"）要写**正向数量锁定**：
  `EXACTLY one sack, never a second one` 要改写成
  `One sack only, fully occupying the frame.`

### 3.1 系统 UI 组件（系统流题材必建）

系统流漫剧的招牌就是系统界面。这些**零算力、纯后期**，但必须**先定尺寸与安全区**，
否则后期加会压到人脸。建议作为独立图层库管理：

| 组件 | 说明 |
|---|---|
| 提示框底板 | 半透明科技感面板，竖屏安全区内 |
| 文字打字机 | 逐字出现动效 |
| 确认/举报按钮 | 高亮态与按下态 |
| 冻结/定格 | 画面去色 + 描边 + 时间停滞 |
| 印章/盖章 | 违规判定落章 |
| 进度条/加载 | 系统处理中 |

**安全区**：与字幕共用 `safe_bottom_px`，且**不得覆盖人物面部区域**
（面部区域 = 画面上 1/3 到 2/3 之间的中心带）。

## 六、实测踩坑记录（出图前必读）

### 6.1 Qwen-Image-Edit 会继承参考图的构图 —— 每个视图必须配同角度参考图

**这是最贵的一个坑。** 用一张头部特写当所有视图的参考图，结果：

- `head_front` 和 `head_side` 生成出来**全是 3/4 视角**（模型照抄了参考图的角度）；
- `body_back` 直接生成成了**半身像**，根本没有全身。

提示词里写"正面视角""从头顶到鞋底完整入画"**完全无效**，
甚至写了 exclude 也不管用 —— 编辑模型的结构先验来自输入图，不是文本。

**规则**：`VIEWS` 里每个视图显式绑定一张**同角度、同构图**的参考图。
新项目没有历史资产时，先用纯文生图出一张"中性站姿全身"，再以它为参考逐角度派生。

### 6.2 全身图"砍头"要按头身比算裁切线，不能盲切比例

做法：用背景色分割定位人物 bounding box → 头顶 = bbox 上缘 → 头高 = 身高 / 头身比，
从头顶往下裁到 `头高 × 1.30`。1.30 大致是肩线位置。

- 裁到 `×1.06` 会留下一截光秃秃的脖子，看起来像"被削掉头的脖子柱"；
- 裁到 `×1.30` 才是干净的肩部断面。

因为按 bbox 定位而不是按画面比例，**即使模型不遵守"头顶留白"的构图指令也裁得对**。

### 6.3 "均匀平光"目前达不到，要预留后期处理

实测多轮，生成结果仍会带：

- 左上方方向性主光（下颌在颈部投影、衣褶阴影）；
- 四角暗角；
- 地面接触阴影。

提示词可以减轻但压不干净。**结论**：资产图应在生成后过一道
"去暗角 + 拉平光比 + 统一背景灰度"的后期处理，不要指望一次出图达标。
同一组资产的背景灰度必须统一（实测三张头部图的背景灰度能差 20 级）。

### 6.4 跨图一致性靠"标志特征"而不是靠模型自觉

同一角色的三张头部图，**胡渣量、皮肤干净度、脸的"沧桑感"会漂移**，
疤痕会变形甚至在某一张里完全消失。

**规则**：
1. 标志特征（疤/痣/异色瞳）必须在设定里写死**位置 + 长度 + 对比度**，写进每一张图的提示词；
2. 生成后逐张核验标志特征，不一致的重出；
3. 瞳孔高光点要显式要求 —— 默认为"死眼"（纯深棕实心，无高光）。

### 6.5 正反面不共享三维坐标

同一角色的正面图与背面图，腰带结的位置、随身道具的前后挂点、
衣摆的磨损形态都会互相矛盾 —— 这是逐张独立生成不可避免的。

**规则**：道具挂点必须在设定里写死"左后腰/右腰侧"等锚定描述，
并在正反面图上人工核对；矛盾时以侧视图为准重出正面或背面。
