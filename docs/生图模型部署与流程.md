### 换机位：Multiple-Angles LoRA（**必需**）

- 文件：`loras/qwen-image-edit-2511-multiple-angles-lora.safetensors`（**281 MB**）
- 来源：`fal/Qwen-Image-Edit-2511-Multiple-Angles-LoRA`（仓库里带官方
  `comfyui-workflow-multiple-angles.json` 与 96 条提示词全表）
- 语法：**`<sks> [方位角] [仰角] [距离]`**（8 × 4 × 3 = 96 个机位）

| 方位角（8） | 仰角（4） | 距离（3） |
| --- | --- | --- |
| `front view` | `low-angle shot`（-30°） | `close-up`（×0.6） |
| `front-right quarter view` | `eye-level shot`（0°） | `medium shot`（×1.0） |
| `right side view` | `elevated shot`（+30°） | `wide shot`（×1.8） |
| `back-right quarter view` | `high-angle shot`（+60°） | |
| `back view` / `back-left quarter view` | | |
| `left side view` / `front-left quarter view` | | |

⚠️ **三条实测**（详见证据文档）：
1. **光有语法不够，LoRA 是必需的**——裸 edit 链 4 组（含 50 步/CFG 4.0）全不动；
2. **45° 四分之一视角在平整正面主体上看不出来**，要角度差就用 `side view`(90°) 或 `high-angle`；
3. **`back view` 有 3D 一致性缺陷**：朝向翻对了、**纵深没搬**（横幅仍占满上缘、尺寸不变）。
   **镜像 ≠ 纵深正确**，别拿它做需要严格空间关系的镜头。

工作流：`workflows/scene/SCN_03b_edit_viewpoint_lora.json`（40 秒/张）。
⚠️ 官方链前面挂 `FluxKontextImageScale`，**输出尺寸会变**（1664×928 → 1392×752）。

## 风格锁定（画风唯一口径）

**2026-09-19 用户拍板：「干净写实」**（对照实验里的 PH15 配方）。

| 环节 | 写法 |
| --- | --- |
| 正向风格句（逐字复用） | `整体为动漫插画风格。` |
| 负向（只在 50 步 / CFG 4.0 生效） | `摄影, 照片, 实拍, 真人照片, 写实摄影, 皮肤毛孔特写, 胶片颗粒, 相机, 镜头虚化` ＋ 常规的 `多余人物/文字/水印/边框/灰色背景` |
| edit 步（8 步 / CFG 1.0） | **不要重复声明画风**，只写"渲染风格与 Image 1 完全一致" |

⚠️ 中途改这段字 = 全片风格漂移。项目调研里的原话：**"渲染一致性：全片统一模型、CFG、采样器、风格词"**。

## 关键陷阱（踩过并有实测证据）

1. **负向词只在 CFG > 1 时生效**——8 步 Lightning 是 CFG 1.0，负向词完全不参与计算。
2. **泛类别风格词拉不动 2512**（"3D渲染/动漫插画/游戏CG"→ 仍出真人）；**具名风格一拉就动**
   （"皮克斯三维动画电影风格"、"日本二维动画赛璐璐上色风格"）。
3. **"追求无瑕"的提示词直接导致塑料感**——官方负向词里就禁 `过度光滑/蜡像感/画面具有AI感`。
4. **全身件里不能写脸部/毛孔类描述**：那会把镜头拽成半身特写。
5. **逐件独立 t2i 必然脸漂**（实测三张不同的脸、背面像画成正脸）→ 必须锚图派生。
6. **细节件不能用 t2i 独立生成**：那不是卡上那件衣服（颜色/织纹/画风都会漂）。
7. **LoRA 节点可能"断开"而非"旁路"**：`outputs.links` 为空时，改 mode 无效，必须重接线。
8. **fp8 基座 + bf16 训练的 LoRA** 是官方标注 ❌ 的组合（网格伪影，Issue #32）。
9. **1MB Range 测速不代表真实速度**（曾 1.9 MB/s vs 实际 17 MB/s），只用来判断"能不能连"。
10. **下载大模型前先算盘**：源不通就什么都不删。
11. **画风 = 锁定句 ＋ CFG 共同决定**（2026-09-19 晚实测）：同一个 `整体为动漫插画风格。`，
    **CFG 1.0 → 半写实（"干净写实"）｜CFG 2.0 → 开始平涂｜CFG 4.0 → 满屏黑勾边、完全二维动画**。
    **锁定句不锁 CFG 等于没锁死。**
12. **负向词搬错家也会推高"动画化"**：禁 `塑料皮肤/磨皮/陶瓷皮肤/蜡像感` 会把模型逼向勾边平涂。
    "干净写实"的负向必须是 PH15 那一套（**禁摄影向**）。
13. **正向里不要提"胡子"**：写「刚刮过胡子」→ 三版全长胡子；只写「面部干净、皮肤光洁」→ 胡子消失。
    **提"不要什么"里的名词，本身就在召唤它**（CFG 1.0 又没有负向对冲）。
14. **提示词别写太长**：项目给 PH14–PH17 定的规矩是"人像描述压到 150 字内"。
    写 310 字会稀释画风、互相抢权重。`#FFFFFF` 这类色码是噪声。

## 下载源结论（2026-09-19 晚更新）

**单连接测速会严重低估，必须试并行**（281 MB 的 angles LoRA 实测）：

| 源 | 单连接 | 8 路并行 | 16 路并行 |
| --- | --- | --- | --- |
| hf-mirror.com | 196 KB/s | 950 KB/s | — |
| **hf-api.gitee.com** | **580 KB/s** | **2457 KB/s** | **4.16 MB/s ✅（68 秒下完）** |
| huggingface.co | 不可达（http=000） | — | — |
| modelscope.cn | 2.8 MB/s（但这个 LoRA 没有副本） | — | — |

大文件一律：**列源 → HEAD → ≥16 MB 大样本 Range 实测 → 算盘（留 10%）→
`dl_chunked.py` 分块并行下 → 校验文件头**。规矩见 `agent.md` 第四节。
