## 换电脑续接

1. 在新电脑拉取本次更新的仓库提交。当前云主机为 `connect.weste.seetacloud.com:38890`，保持运行；确认 `ssh/server.txt` 指向该地址。SSH 口令文件需在新电脑单独安全配置，不进入仓库。
2. 在两个终端分别启动隧道：

   ```powershell
   python .work/tunnel_comfyui.py 8187 8188
   python ssh/tunnel_comfy.py
   ```

   H3 使用本地 `http://127.0.0.1:8187`；Qwen-Image 2.1 使用本地 `http://127.0.0.1:8188`。云服务器保持运行。

3. 已完成整片，无需继续生成。若要单独重跑返家镜头，首帧已在 `outputs/QWEN21_STYLE_V1/Q21_KEYFRAME_S01_return_home_v1.png`；重新上传至 H3 ComfyUI 输入目录后运行：

   ```powershell
   $env:COMFY_BASE='http://127.0.0.1:8187'
   python tools/run.py '美食：全市巡摆，馋哭食客' QWEN21_V1_H3_S01_return_home --skip-gate --timeout 2400
   Remove-Item Env:\COMFY_BASE
   ```

4. 需要重合成时运行 `.work/assemble_qwen21_visual_cut.py`。H3 原生音轨没有混入本版；后续如需要对白，应作为单独配音/混音步骤处理。

生产门禁检查：`python tools/production_guard.py verify-workflow '美食：全市巡摆，馋哭食客' QWEN21_V1_H3_S01_return_home`。执行器需设置 `COMFY_BASE` 为 8187。若只想看成片，直接打开上面的视觉版文件。
