## 一、参考片脚本 ≠ 原著第 2 章（**两处实质差异**）

旧仓库 `projects/买肉/source/买肉.txt` 是一份**改写**，它描述的就是参考片的画面。
它和本项目 `source/originals/002_第2章 新鲜的二师兄.md` **不是同一场戏**：

| 项 | **原著第2章**（本项目 `script/EP02_SC01` 采用） | **旧线 `买肉.txt`**（＝参考片内容） |
|---|---|---|
| 时间 | **凌晨四点半**（天没亮，收尾时天亮） | **下午四点**（生意淡下来） |
| 男主交通 | **小电驴** | **浅蓝色复古踏板车** |
| "新鲜"的证据 | 老板**放一段视频**：**一车活蹦乱跳的二师兄正被卡车拉进屠宰场** ← **这是原著的笑点** | 老板**给看一张照片**：停在**猪场门口**的货车，照片时间**当天早上六点十七分** |
| 笑点性质 | **荒诞**（活猪进屠宰场＝新鲜） | **平淡**（猪场门口的照片） |

> ★ **本项目按原著写**（用户指定「写第二章的买肉剧情」），所以 `EP02_SC01` 的 B4 是**屠宰场视频**那个荒诞笑点。

## 二、H3 六段式：字段名与顺序（**照抄，不许改名换序**）

```
subject_definitions:  →
summary:              →
retention_analysis:   →
detailed_description: →
overall_soundscape:   →
non_diegetic_music:
```

**S01 自检表（旧线的做法，本项目沿用）**：

| 检查 | 要求 |
|---|---|
| 六段齐全且顺序正确 | ✅ |
| `detailed_description` 词数 | **官方建议 350–500**（S01 实测 372） |
| 四张参考图都被点名 | ✅ |
| 无 `<d>` 台词段时 | 不写就是 |
| **含禁字幕句** | 有台词时**必须**含 `No subtitles, captions or on-screen text appear at any point.` |

| 含动机光源 | ✅ |
| 含阴影方向 | ✅ |
| 风格句位置 | 在 `[Shot 1]` **之前** |

## 三、★ 帧数与秒数：旧线用真实返工换来的四条

| # | 规则 | 代价（原文） |
|---|---|---|
| 1 | **帧数必须落在 `17k+5`** | 旧版请求 162/198/170/94 → 被吸附成 175/209/175/107 |
| 2 | **动作必须带秒数预算，否则没有落点** | S01「三帧里他都在骑：0.2s 车头刚进画面左缘 → 3.5s 骑行中 → 7.0s 仍在骑，**始终没有停住**」——7.29 秒全用在骑进来 |

## 四、其余失败经验（逐条，含未解决的）

| # | 经验 | 状态 |
|---|---|---|
| 1 | **拆件细节件会画成人像**（4 格里 3 格变头肩像）。修法：**拿掉角色描述整段** ＋ 负向词封 `人脸,人像,人物,半身像,全身像,头,肩膀` | ✅ 已解决（复测 4/4） |
| 2 | **全身视图被裁到大腿、背面像画成正面**。修法：把画面占比与「能/不能看到什么」写死 | ⚠️ 男主 3/3 达标，**摊主 3/3 仍被裁在大腿 —— 未解决** |
| 3 | **画风偏卡通来自"设定表词汇"**（`character model sheet` / `orthogonal views` / `illustration`） | ✅ 已定位 |
| 4 | **4 步只是官方"最快、质量最低"档**（默认 20 步）；另有**无报错缺陷**：4 步 `ref2v_turbo_4step_v0.1` 会让**相机不受控漂移**（条件：接了参考视频）。本片不用 `ref_videos`，S01 未复现 | ⚠️ 已知 |
| 5 | **首帧就是构图；景别必须在首帧里做出来**，不能靠文字在 H3 里改 | ✅ |
| 6 | **H3 的身份优先级：首帧 ≫ 参考图 > 文字** | ✅ |
| 7 | **S04 景别偏差**：锁定 Z3 近景，实际做出 Z4 中景；**试过三次都推不近**，最后用数字裁切把首帧裁紧 1.4 倍 | ⚠️ 折中 |
| 8 | **S03 编码偏差**：锁定 F6 过肩，实际接近 Z4-Y4-X2-F1 | ⚠️ 未修 |

| 10 | **音频内容没听过** —— 只验了流参数与音量；**台词对不对、有没有烧字幕，需要人听/看** | ⚠️ **未做** |
| 11 | 8 步 vs 4 步**缺同 seed 对照组** | ⚠️ 未做 |
| 12 | 五段锁定 §7 暴露的**锁定本身的问题**：光线只写"暖色菜市场照明"；机位只写 `a static medium two-shot`；**防跳轴没写**；遮挡靠事后发现（**S02 被肉挡了 8 秒**）；台词预算没算过 | ✅ 本轮已补进锁定段 |
